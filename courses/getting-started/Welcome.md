# Welcome to your course library

This is a starter guide, not material from one of your courses.

## Add a course

1. Create a folder inside `courses/`, such as `courses/linear-algebra/`.
2. Add your PDFs, notes, slides, code, or other learning materials. Nested folders are supported.
3. Optionally add a `course.json` file with a title, description, and category.
4. Commit and push to GitHub. The Pages workflow rebuilds the library automatically.

Example course.json:

```json
{
  "title": "Linear Algebra",
  "description": "Notes, problem sets, and readings.",
  "category": "Mathematics"
}
```

Visitors can search by file name or course, filter by file type, open files, and download them.
Remove the getting-started folder when you no longer need this guide.

Only add files you want to make public and have permission to share.
